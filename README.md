# kwan0kim.github.io

- `index.html` contains the home page.
- `pages/` contains the other pages. The permalink at the top of each file sets its public address.
- `assets/` contains styles, scripts, and site images. Profile images live in `assets/images/`.
- `materials/` holds public PDFs, slides, posters, and other downloadable files. Group files by section as you add them, for example `materials/publications/` or `materials/coursework/`.
